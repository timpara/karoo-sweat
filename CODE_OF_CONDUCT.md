# Code of conduct

## In short

Be decent. Assume good faith. Disagree about the physics, not about the person.

## Expected behaviour

- Be respectful of differing viewpoints and experience levels.
- Accept constructive criticism gracefully. Technical review is about the code and
  the model, not about you.
- Give constructive criticism kindly and specifically.
- Focus on what is best for people actually using this on a bike.

## Unacceptable behaviour

- Harassment, insults, or derogatory comments, public or private.
- Personal or political attacks.
- Publishing others' private information without permission.
- Any conduct that would reasonably be considered inappropriate in a professional
  setting.

## Enforcement

Report problems by opening an issue or contacting the maintainer privately.
Maintainers may remove comments, commits, code or issues that violate this policy,
and may ban contributors for repeated or severe violations.
